# Escopo Jurídico Brasileiro

O PDF_Crusher é neutro quanto à área do direito. O objetivo é preparar contexto documental para LLM, não interpretar mérito.

Pode ser usado, com revisão humana, em documentos:

- cíveis;
- trabalhistas;
- previdenciários;
- tributários;
- criminais;
- empresariais;
- administrativos;
- família e sucessões;
- consumidor;
- fazenda pública;
- execução e cumprimento de sentença.

As detecções são preliminares. Uma página marcada como possível decisão, possível petição ou possível prova deve ser confirmada no texto antes de qualquer conclusão.

Idioma preferencial: português brasileiro jurídico.
