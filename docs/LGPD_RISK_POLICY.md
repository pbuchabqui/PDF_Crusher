# Política de risco LGPD

Este projeto faz higienização assistida. Ele não garante anonimização irreversível.

Regras práticas:

- Não subir PDFs reais no GitHub.
- Não versionar saídas contendo dados pessoais.
- Revisar manualmente o Markdown final.
- Usar Groq apenas quando o envio externo for aceitável para o caso concreto.
- Não usar em segredo de justiça sem validação específica.
